API Key Gemini

Dipakai untuk memproses cerita menjadi baris laporan. Setiap dosen memakai key miliknya sendiri.

Cara mendapatkan API key (gratis)
  1. Buka aistudio.google.com/apikey dengan akun Google Anda.
  2. Klik Create API key.
  3. Salin key (diawali AIza), tempel di kolom di atas, lalu Simpan Key.

Key disimpan di spreadsheet Master DB tanpa enkripsi dan hanya dapat dilihat admin sistem. Jangan bagikan key Anda ke orang lain.
